# AI Campus

AI 기초, 프롬프트 작성, 에이전트 설계, 도구 연결, 업무 활용을 배우는 한국어 실무 AI 교육 사이트입니다. 특정 회사나 제품에 종속되지 않는 공통 개념을 다룹니다.

## 실행

Node.js 24 LTS를 권장합니다.

```powershell
npm ci
npm run dev
```

터미널에 표시된 로컬 주소를 엽니다.

## 주요 기능

- 5개 교육과정과 15개 레슨, 실습 과제
- 16개 기초 용어의 쉬운 설명과 검색 팝업
- 프롬프트 템플릿과 복사 기능
- 3D 신경망 모션
- 브라우저 로컬 저장소 기반 자가 학습 체크

학습 체크는 공식 수료 기록이 아니며 계정 간에 동기화되지 않습니다. 이 사이트는 외부 서비스와 직접 연결되어 있지 않습니다. 실습 전 사용할 도구의 공식 문서, 권한과 데이터 처리 정책을 확인하세요.

## 내용 수정

- `src/brand.js`: 사이트명, 교육과정, 레슨과 프롬프트
- `src/glossary-data.js`: 용어집 설명
- `src/main.js`, `src/glossary.js`: 상호작용
- `src/style.css`: 디자인
- `src/scene.js`: 3D 장면

## 빌드와 배포 상태

```powershell
npm run build
npm run preview
```

배포는 현재 중지되어 있습니다. `.github/workflows/deploy-pages.yml`에는 수동 실행만 남아 있으며, 코드 업로드만으로 자동 배포되지 않습니다. 다시 공개하려면 저장소 공개 범위와 Pages 설정을 별도로 확인해야 합니다.

원본 스타터의 예시 자료는 `samples/`와 `prompts/`에 남아 있습니다.
